# 버거리 메뉴 투표

## 실행

Node.js 18 이상에서 프로젝트 폴더를 열고 실행합니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 같은 사내 네트워크의 다른 기기에서도 사용하려면 앱을 실행하는 컴퓨터에서 `npm run start:lan`을 실행한 뒤, 다른 기기에서 해당 컴퓨터의 내부 IP 주소와 `:3000`으로 접속하세요.

투표는 실행 컴퓨터의 `votes.json`에 저장되며, 한국 시간 기준 날짜가 바뀌면 새 투표로 시작합니다. 같은 이름이나 별명으로 다시 투표하면 기존 표가 수정됩니다. 이름은 중복 투표 방지에 사용하고 화면에는 표시하지 않습니다.

## 메뉴 목록

메뉴명, 설명, 단품·세트 가격과 사진은 [버거리 나주혁신점 네이버 플레이스](https://map.naver.com/p/entry/place/1446888132)의 주문 메뉴를 기준으로 정리했습니다. 메뉴·가격은 매장 사정에 따라 변경될 수 있습니다. 세트 사이드 변경 가능 여부와 추가 금액은 주문 전에 네이버 주문 화면에서 확인해 주세요. 메뉴 사진은 네이버 플레이스에서 제공하는 이미지를 표시합니다.
